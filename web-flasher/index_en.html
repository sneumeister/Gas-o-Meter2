ESP32-C6 · Web Serial

Gas-O-Meter2 Web Flasher

Install firmware in the browser without PlatformIO. Supported on Firefox 151+ (desktop), Chrome, and Edge over HTTPS.

Firefox: On first connect, Firefox prompts to install an automatically generated, site-specific permission extension. Then select the serial port. No extra third-party extension is required.

1. Select target

First select the matching board or test version.

2. Connect and flash

Connect the XIAO ESP32-C6 via USB, check the selection, then click “Connect”.

Warning: TPL_test replaces production firmware and is only for the TPL5110 / reed test. Flash the matching PCB firmware afterward.
Important: In the ESP Web Tools dialog, never choose “Erase device” for Firmware or LittleFS updates. A full erase would remove bootloader, partition table, and persistent data.
Web Serial is not supported in this browser. Use Firefox 151+ (desktop), Chrome, or Edge. Web Serial is not available here. Open the page over HTTPS.

Which install type?

Complete
For first install and when the release notes mark Breaking for partition table or bootloader changes. PCB Complete overwrites saved configuration, NVS ring buffer, and Zigbee data; TPL_test Complete ends after the test firmware.
Firmware
Updates program code only. Counter ring buffer and LittleFS stay intact.
LittleFS
Updates web UI and shipped default configuration only. The current device configuration is overwritten. Not available for TPL_test.
