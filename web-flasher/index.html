ESP32-C6 · Web Serial

Gas-O-Meter2 Web-Flasher

Firmware ohne PlatformIO direkt im Browser installieren. Unterstützt werden Firefox ab Version 151 (Desktop), Chrome und Edge über HTTPS.

Firefox: Beim ersten Verbinden fordert Firefox zur Installation einer automatisch erzeugten, seitenspezifischen Berechtigungs-Erweiterung auf. Danach den seriellen Port auswählen. Eine zusätzliche Drittanbieter-Erweiterung ist nicht erforderlich.

1. Ziel auswählen

Wähle zuerst die passende Platinen- bzw. Testversion.

2. Verbinden und flashen

XIAO ESP32-C6 per USB verbinden, Auswahl kontrollieren und anschließend „Connect“ anklicken.

Achtung: TPL_test ersetzt die Produktiv-Firmware und dient nur dem TPL5110-/Reed-Test. Danach wieder die passende PCB-Firmware flashen.
Wichtig: Im ESP-Web-Tools-Dialog bei Firmware- oder LittleFS-Updates niemals „Erase device“ wählen. Ein vollständiges Löschen würde Bootloader, Partitionstabelle und persistente Daten entfernen.
Web Serial wird von diesem Browser nicht unterstützt. Bitte Firefox ab Version 151 (Desktop), Chrome oder Edge verwenden. Web Serial ist hier nicht verfügbar. Die Seite muss über HTTPS geöffnet werden.

Welche Installationsart?

Complete
Für die Erstinstallation und wenn die Release Notes Breaking wegen Partitionstabelle oder Bootloader nennen. PCB-Complete überschreibt gespeicherte Konfiguration, NVS-Ringspeicher und Zigbee-Daten; TPL_test Complete endet nach der Test-Firmware.
Firmware
Aktualisiert nur den Programmcode. Zähler-Ringspeicher und LittleFS bleiben erhalten.
LittleFS
Aktualisiert nur Web-UI und mitgelieferte Default-Konfiguration. Die aktuelle Gerätekonfiguration wird überschrieben. Nicht für TPL_test verfügbar.
